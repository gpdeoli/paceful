# Paceful

**Paceful** é um aplicativo Android em desenvolvimento para ajudar na organização e agendamento de estudos, permitindo que você mantenha o controle do seu aprendizado de forma eficiente e estruturada.

## 🎯 Objetivo

O objetivo principal do aplicativo é oferecer uma ferramenta para registrar, organizar e acompanhar o progresso de estudos e seus respectivos tópicos, facilitando o cumprimento de prazos e a gestão do tempo de estudo.

## ✨ Funcionalidades

### 📚 Gerenciamento de Estudos
Crie e organize seus planos de estudo com informações detalhadas:
*   **Nome**
*   **Prazo (Deadline)**
*   **Status de Progresso**
    *   ⏳ **Pendente**
    *   📅 **Agendado**
    *   🚧 **Em andamento**
    *   ✅ **Concluído**

### 📝 Tópicos de Estudo
Para um aprendizado mais granular, cada Estudo pode conter múltiplos Tópicos:
*   Adicione **Tópicos** relacionados a um estudo principal.
*   Insira **Nome** para detalhar o conteúdo do tópico.
*   Defina um **Prazo Opcional** específico para cada tópico, permitindo um controle mais fino do cronograma.

## 🛠️ Tecnologias e Arquitetura

O projeto utiliza tecnologias modernas do ecossistema Android:

*   **Linguagem:** [Kotlin](https://kotlinlang.org/)
*   **Interface de Usuário:** [Jetpack Compose](https://developer.android.com/jetpack/compose) com Material Design 3 Adaptive
*   **Banco de Dados Local:** [Room](https://developer.android.com/training/data-storage/room)
*   **Injeção de Dependência:** [Koin](https://insert-koin.io/)
*   **Navegação:** Navigation3
